# Мои финансы — персональный трекер

Одностраничное приложение для учёта личных финансов. Работает в браузере без регистрации и сервера.

## Возможности

- Доходы, расходы и переводы между счетами.
- Счета с начальными и текущими остатками.
- Категории и месячные бюджеты с предупреждениями.
- Финансовые цели и калькулятор накоплений.
- Регулярные платежи с защитой от повторного проведения одной даты.
- Аналитика, графики, фильтры и поиск.
- Экспорт транзакций в CSV и резервной копии в JSON, импорт JSON.
- Светлая, тёмная и системная тема.

## Запуск локально

Откройте `index.html` в современном браузере. Для публикации используйте GitHub Pages — сборка не требуется.

## Публикация на GitHub Pages

1. Создайте публичный репозиторий на GitHub (на GitHub Free GitHub Pages доступен для публичных репозиториев; доступ к Pages для приватных зависит от тарифа), например `my-finances`.
2. Загрузите в корень репозитория файл `index.html`, папку `.github` и этот `README.md`.
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **GitHub Actions**.
5. Перейдите во вкладку **Actions** и дождитесь завершения workflow `Deploy to GitHub Pages`.
6. После успешного запуска адрес сайта появится в настройках Pages (обычно `https://ВАШ-ЛОГИН.github.io/ИМЯ-РЕПОЗИТОРИЯ/`).

В репозитории уже есть workflow `.github/workflows/pages.yml`, который публикует статический сайт при каждом push в ветку `main`.

## Где хранятся данные

Операции и настройки хранятся в IndexedDB браузера на текущем устройстве и в текущем браузерном профиле. Данные не отправляются на GitHub и не синхронизируются между устройствами. Очистка данных сайта или браузера может удалить локальную базу — регулярно скачивайте JSON-резервную копию в разделе «Настройки». После публикации на другом домене приложение будет иметь отдельное хранилище.

## Важное

- Для загрузки Chart.js с CDN и отображения графиков требуется интернет. Остальные основные функции работают локально.
- GitHub Pages публикует только статические файлы. В проекте нет сервера и подключения к банковским счетам.
- Не храните в приложении номера карт, пароли и другие секретные платёжные данные.
